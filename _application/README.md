# MORARG · Morality, Between Us

A sourced human-morality argument in twelve connected rooms, with conditional response paths, three case studies, ten objection alcoves and a complete reading alternative. The current build version is in `scaffold.mjs`; `data.mjs` and `paths.mjs` define the authored questions.

From this directory: `npm run build`, `npm test`, `npm run dev`.

The preview is local only. No packages are required. Commands, architecture and provenance are documented in `../_documentation/DEVELOPMENT.md`; research in `../_documentation/ARGUMENT_CORPUS.md`; durable identity/environment in `../project.md` and `../projects.md`.

Active wall diagrams present the argument; inherited photographs are preserved in the package. The defended thesis is that adequate intersubjective justification constitutes human interpersonal moral validity, with personal judgment and accountability. Its premises and rival explanations remain inspectable. Responses, values, working notes and consistency explanations live in page memory with optional private JSON download.
